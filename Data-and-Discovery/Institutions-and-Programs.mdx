Every institution in Manifest is keyed on its AISHE code, the government's own primary identifier. This guarantees no duplication and means every record can be cross-checked against the source AISHE dataset at any time.

## What a record contains

Each institution carries more than 80 fields, organized into ten categories.

| Category | Covers | Source |
| --- | --- | --- |
| Identity | AISHE code, name, short name, type, category, ownership | AISHE |
| Location | State, city, address, pincode, coordinates | AISHE |
| Contact | Website, email, phone | Web enrichment |
| Academic | Year established, stream, student strength, faculty count, campus size | AISHE and web |
| Rankings | NIRF rank and score across overall, engineering, medical, management, law, university, college, research, and pharmacy categories | NIRF |
| Accreditation | NAAC grade and CGPA, assessment year, NBA accreditation, approval status | NAAC and UGC |
| Placements | Average, median, and highest package, placement percentage, top recruiters | Web enrichment |
| Infrastructure | Hostel availability, library, sports, medical facility, WiFi, hostel capacity | Web enrichment |
| Programs | Programs offered, entrance exams accepted, disciplines, total courses | Web enrichment |
| Content | Description, logo, cover image, photos, annual fests, clubs and societies | Web enrichment |

A meta category tracks `data_completeness`, `data_source`, and `last_enriched_at` for every record, so it is always visible how current and how complete a given institution's page is.

## Programs and courses

Program data sits in its own table, linked to the parent institution by AISHE code. Each course record carries:

- Course name, level (UG, PG, or PhD), and stream
- Total seats and annual tuition fee
- Entrance exams accepted for that course

This lets a student move from an institution-level view down to a specific course, its seats, and its cost, without leaving the profile.

## How fields get filled in

Identity, location, and academic fields come directly from AISHE's own census. Rankings and accreditation come from NIRF and NAAC's published data. Everything else, including contact details, placements, infrastructure, and program lists, comes from a website enrichment pipeline that reads an institution's own site. Coverage varies by field. Where enrichment has not yet produced a value, the field is left empty rather than filled with a guess, and the record's completeness score reflects that gap.

<Note>
  A field with no data on Manifest means Manifest has not verified it yet, not that the institution lacks it. Completeness is shown per record so this distinction is never hidden from the student.
</Note>
