Manifest is built to be useful the moment a student lands on it, without an account and without a prior sense of what they are looking for. Search, filters, and browse are three different entry points into the same registry.

## Search

A student can search by:

- College or university name
- City or state
- Program or course
- Entrance exam

Search runs against the full registry of 70,623\+ institutions, with autocomplete surfacing matches as the student types.

## Filters

Once a student has a starting point, filters narrow the result set without a new search.

| Filter | Narrows by |
| --- | --- |
| State and city | Location |
| Stream | Discipline, such as engineering or medicine |
| Institution type | University, affiliated college, standalone, constituent |
| Ownership | Government or private |
| NIRF | Ranking category and range |
| NAAC | Accreditation grade |
| Fees | Cost range |
| Placements | Package range |
| Entrance exams | Which exam is accepted |
| Scholarships, hostel, campus size, established year | Additional refinement |

## Sort

Results can be ordered by relevance, NIRF rank, NAAC grade, fees, placements, year established, recently updated, or alphabetically.

## Browse

The homepage surfaces institutions without requiring a search at all:

- **Featured colleges**, curated and hand-verified
- **Trending institutions**, based on current student interest
- **Recently updated**, reflecting the newest enrichment and ranking data
- **Top ranked**, pulled directly from NIRF

## What's next for search

Planned improvements move search from keyword matching toward genuine natural-language queries, for example "best CSE colleges under 2 lakh fees in Delhi," backed by a full-text index rather than pattern matching. This is a search quality upgrade, not a change in what data underlies the result: every answer still traces back to the same verified registry described in [Institutions and Programs](/data-and-discovery/the-repository/institutions-and-programs).
